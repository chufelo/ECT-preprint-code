# Current preprint scripts

This directory contains only current reproducibility material: figure generators, calculations, SPARC analysis, Graphviz sources, the PES verification package, and the preprint build entry point.

- Build: `bash compile_preprint.sh` from this directory or `bash LaTex/scripts/compile_preprint.sh` from the ECT root.
- Data: `../data/`.
- Figure outputs: `../figures/`.
- PES verification: `verification/pes/`.
- Historical one-off patch, commit, repair, and integration scripts are preserved under the workspace `.archive/legacy/scripts/` and are not active tooling.

The detailed figure/calculation inventory is maintained in `../README.md`.
