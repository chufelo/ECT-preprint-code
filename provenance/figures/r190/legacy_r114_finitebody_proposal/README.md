These two scripts are preserved only as provenance for the proposal-stage
R114 renderer.  They are not part of the active public verification surface:
the publication uses later R123/R127/R148 presentation successors, while the
underlying R114 numerical estimator is verified independently under
`scripts/verification/r114/`.

The historical verifier also used a five-document insertion census that is
outside the current English-only publication boundary.  Do not run it as a
release gate.  Its presence here does not upgrade the fixed-metric scalar
proxy to a Cassini, WEP, or full-PPN prediction.
